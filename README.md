# Stardew Valley 1x1 Farm

Ein kleines Lernspiel zum Einmaleins im Stil von Stardew Valley. Auf einer Farm werden Pflanzen in Reihen gesetzt, und die Kinder rechnen aus, wie viel Dünger gebraucht wird. Für richtige Antworten gibt es Sterne.

## So wird gespielt
1. Jahreszeit wählen: Frühling (leicht, 1 bis 4), Sommer (mittel, 5 bis 7) oder Herbst (schwer, 8 bis 10).
2. Schritt 1: neue Aufgabe. Schritt 2: Felder zeigen. Schritt 3: Rechnung zeigen.
3. Ergebnis eintragen und prüfen. Die Aufgabe lässt sich als Raster oder als Gruppen anzeigen, das hilft beim Verstehen der Multiplikation.

## Starten
Direkt im Browser spielen: https://mrbraendt.github.io/StardewValley-1x1/

Oder `index.html` herunterladen und im Browser öffnen. Es wird nichts installiert und nichts gespeichert.
